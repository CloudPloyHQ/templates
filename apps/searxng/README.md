# SearXNG

The official SearXNG image (`searxng/searxng:2026.11.26-b5605b8f2`, AGPL-3.0) with an HTTPS address.

- No accounts and no data to keep, so there is no setup, volume or database, and it can run more than one copy.
- Anyone with the address can search through it. Search engines may slow down or block a busy server's address.
